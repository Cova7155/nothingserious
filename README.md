# godpack DEX

A daily Pokémon quiz by godpack.io. Seven prompts a day, the same for everyone. Obvious answers pull Commons, deep cuts pull God Pulls.

Live: https://godpack-dex.godpack-live-worker.workers.dev

## What's in here

| Path | What it is |
|---|---|
| `public/index.html` | The page shell. All SEO tags (title, description, Open Graph, Twitter) live in its `<head>`. |
| `public/js/app.js` | The whole front end: every screen, the play loop, results, boards, Hot Pack party. |
| `public/js/core.js` | Game rules shared by the browser and the API: matching names, rarity tiers, scoring, daily packs. |
| `public/data/dex.json` | All 1,025 Pokémon, 470 prompts and the daily schedule. Generated by `tools/build_db.mjs`. |
| `public/css/app.css` | All styles. |
| `public/_headers` | Caching rules for Cloudflare. |
| `src/worker.js` | The API under `/api/*`: players, server-checked daily scores, leaderboards, friends. |
| `src/room.js` | Hot Pack party rooms (one Cloudflare Durable Object per room). |
| `schema.sql` | Leaderboard database tables (Cloudflare D1). |
| `tools/smoke_test.py` | Plays a full daily pack, the answer sheet and an Unlimited pack in a headless browser. |

## Run it locally

```bash
npx wrangler d1 execute godpack-dex --local --file=schema.sql
npx wrangler dev --port 8788
python3 tools/smoke_test.py   # needs Playwright + Chrome
```

## Deploy

Hosted on Cloudflare Workers (worker `godpack-dex`, D1 database `godpack-dex`).

```bash
CLOUDFLARE_API_TOKEN=... npx wrangler deploy
```

Never commit API tokens.

## How changes get live

1. Tools (like the SEO tool) work on a branch and open a pull request into `main`.
2. Claude reviews the pull request, runs the smoke test, deploys to Cloudflare and merges.

`main` always matches what's live.
