# godpack DEX

A daily Pokémon quiz by godpack.io. Seven prompts a day, the same for everyone. Obvious answers pull Commons, deep cuts pull God Pulls.

Live: https://dex.godpack.live (the old `godpack-dex.godpack-live-worker.workers.dev` address forwards here and brings each player's progress along).

## What's in here

| Path | What it is |

## Accounts

Nobody has to sign up. A player's scores, streak and history live on their device, and a trainer profile is made on the server the first time they post a score, pick a name or add a friend.

To keep their DEX safe or play on another device, a player can **save it with a passkey** (Face ID, fingerprint or screen lock: no email, no password). Signing in with that passkey anywhere brings everything back; if they had played as a guest on that device, the guest's scores fold into their account. Passkeys work on `dex.godpack.live` (and `localhost` for testing). A device key in Settings is the backup for browsers without passkeys.

## Running on its own

Nothing here needs a person to keep it going:

- **Daily packs** are scheduled through 2036 in `dex.json`, then the schedule repeats. Pack numbers follow each player's local date.
- **Every hour** a cron trigger clears expired passkey challenges.
- **Every night (03:05 UTC)** it removes idle guest profiles (no score, no name, no friends, no passkey, 30 days away), sign-ins unused for 400 days, and plays, answer counts and tallies older than 400 days. All-time totals live on the player row and are kept.
- **Optional daily recap**: set a `DISCORD_WEBHOOK_URL` secret and yesterday's top three post to Discord at 14:05 UTC.
- **Party rooms** wipe themselves two hours after the last player leaves.
- **Leaderboards stay cheap at any size**: public boards and answer stats are cached at the edge; ranks come from small per-day tallies and month totals, and month and all-time ranks past 1,000 show as "1k+".
- **Bot runs stay off the boards**: each daily pack gets a signed start ticket (`TICKET_SECRET`). Runs without one (offline) or impossibly fast ones still count for the player's history and streak, just not the public boards. Writes are rate limited.
- **If the backend is down or over a limit**, the game keeps working: packs, scoring and history all run in the browser, and scores post the next time the player opens the game.

### Limits and when to upgrade

On Cloudflare's free plan the database allows about 100,000 written rows a day. Each daily score writes about 23, so the free plan suits up to roughly 3,000–4,000 daily players. Past that, switch the account to Workers Paid ($5 a month), which raises every limit far beyond what this game needs. Storage stays bounded because old rows are pruned nightly.

### Keep-alive checklist

- Keep `godpack.live` renewing (Cloudflare Registrar, auto-renew).
- Secrets on the worker: `TICKET_SECRET` (required, any long random string), `DISCORD_WEBHOOK_URL` (optional).

## Run it locally

```bash
npm install
npx wrangler d1 execute godpack-dex --local --file=schema.sql
npx wrangler dev --local --port 8788 --local-upstream localhost:8788
python3 tools/smoke_test.py   # needs Playwright + Chrome
```

Open http://localhost:8788. `--local-upstream localhost:8788` makes the API see `localhost`, which passkeys need.

## Updating the Pokédex

`node tools/build_db.mjs` rebuilds `public/data/dex.json`. It is append-only: species and prompts keep their numbers and every day already published keeps its pack, so scores already on the boards stay valid. Bump the `?v=` number afterwards (see `AGENTS.md`).

## Deploy

Hosted on Cloudflare Workers (worker `godpack-dex`, D1 database `godpack-dex`, custom domain `dex.godpack.live`).

```bash
CLOUDFLARE_API_TOKEN=... npx wrangler deploy
```

Never commit API tokens.

## How changes get live

1. Tools (like the SEO tool) work on a branch and open a pull request into `main`.
2. Claude reviews the pull request, runs the tests, deploys to Cloudflare and merges.

`main` always matches what's live.
